# Drosophila (Fruit Fly) Brain Connectome Simulation

An open-source initiative to optimize and run biological neural network sub-circuits from the fruit fly connectome on resource-constrained edge hardware.

## Project Objective
This project maps sparse biological networks—specifically Leaky Integrate-and-Fire (LIF) models of the fly's looming and escape visual pathways—into compressed graph structures. The goal is to simulate autonomous survival behaviors without relying on heavy cloud servers.
